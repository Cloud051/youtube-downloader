# YouTube Downloader

A simple YouTube downloader using yt-dlp library.

## What I learned

- **Flexible Functions**: I learned how Python functions can use default values (like automatically naming a file after the video's title) and type hints to keep code clean.
- **Safe Resource Management**: I saw how the ```with``` statement works with ```yt_dlp.YoutubeDL``` to automatically clean up files and network connections when the download finishes.
- **Best Quality & Merging**: I learned how ```yt-dlp``` grabs the best separate video and audio tracks, then combines them into a single playable MP4 file.
- **Console Control**: I discovered how to configure settings (```ydl_opts```) to show helpful download progress while hiding unnecessary warning messages.
